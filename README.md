# Draftcat

The highly opinionated vim editor and go cli project manager. Built to track a series of .md files and folders to make writing projects easier.
Use git for tracking file changes in your project.
Get the best of neovim (LazyVim recommended) for writing and editing while scaffolding and managing your project with draftcat.

## Installation

To download the cli you need go v1.26+ and run

```bash
go install
```

Install [LazyVim](https://www.lazyvim.org/installation)
